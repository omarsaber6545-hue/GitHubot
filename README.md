# 🐙 جيت هَبوت (GitHubot) — بوت المطورين و GitHub الاحترافي لديسكورد

بوت ديسكورد متكامل واحترافي مصمم خصيصاً للمبرمجين، فرق التطوير، والمجتمعات البرمجية. مبني بأحدث التقنيات: **TypeScript**، **Discord.js v14**، **GitHub OAuth**، **تشفير AES-256-GCM**، و **نظام تخزين كاش سريع LRU In-Memory**.

---

## ✨ المميزات الرئيسية

### 🐙 1. تكامل GitHub وإدارة الخصوصية (OAuth)
* **`/github repo:<owner/repo>`** — تحليل شامل لمستودع جيت هب:
  * عدد النجوم ⭐، الفروك 🍴، المشاكل المفتوحة 🐛، حجم المستودع 💾، لغة البرمجة الأساسية 💻، والرخصة ⚖️.
  * تاريخ الإنشاء وآخر تحديث بتوقيت ديسكورد التفاعلي (`<t:...:R>`).
  * تفاصيل آخر إصدار (Release) وآخر كوميت مع اسم المطور والهاش.
  * أزرار تفاعلية للانتقال السريع للمستودع والإصدارات وقائمة المشاكل.
* **`/github-user username:<username>`** — بطاقة الملف الشخصي لمستخدم جيت هب:
  * صورة الحساب (Avatar)، الاسم والنبذة الشخصية (Bio).
  * عدد المستودعات العامة، المتابعين (Followers)، والمتابَعين (Following).
  * الشركة، الموقع الجغرافي، الموقع الإلكتروني، وحساب تويتر/X.
* **`/github-visibility`** — إدارة وتغيير خصوصية المستودعات عبر GitHub OAuth:
  * إمكانية الاختيار: تعديل **مستودع واحد** أو **جميع المستودعات دفعة واحدة (ALL REPOSITORIES)**.
  * التبديل السهل بين **عام (Public 🌐)** و **خاص (Private 🔒)**.
  * معالجة ذكية للـ Rate Limits وتقارير تفصيلية للنجاح والفشل.
* **`/github-auth`** — إدارة ربط حساب GitHub:
  * ربط الحساب، عرض حالة الاتصال، أو إلغاء الربط في أي وقت.
* **`/commits repo:<owner/repo> [count]`** — سجل الكوميتات الأخيرة:
  * عرض آخر 1 إلى 10 كوميتات على الفرع الرئيسي مع نصوص الرسائل وأسماء المبرمجين.
* **`/release repo:<owner/repo>`** — فاحص الإصدارات:
  * وسم الإصدار الأخير (Tag)، اسم الإصدار، تاريخ النشر، عدد الملفات المرفقة، وملخص التحديثات.

---

### 📦 2. متجر حزم NPM
* **`/npm package:<package-name>`** — فحص وتحليل حزم NPM:
  * الإصدار الأخير، الوصف، وإحصائيات التحميلات الأسبوعية (Weekly Downloads).
  * عدد المكتبات المعتمدة (Dependencies)، نوع الرخصة، وحساب المطور.
  * دعم ملفات TypeScript Types مدمجة.
  * أزرار سريعة للانتقال لصفحة NPM، مستودع الكود، وموقع فحص حجم الحزمة Bundlephobia.
* **`/npm-search query:<query>`** — البحث في حزم NPM:
  * أفضل النتائج المطابقة مع معدل التحميلات.
  * **قائمة منسدلة تفاعلية (Select Menu)**: لاختيار أي حزمة وعرض تفاصيلها الكاملة فوراً بضغطة زر.

---

### 📚 3. محرك البحث البرمجي في التوثيق (Documentation)
* **`/docs query:<query> [technology:<tech>]`** — بحث التوثيق البرمجي متعدد التقنيات:
  * دعم التكملة التلقائية لأهم اللغات وأطر العمل: **JavaScript (MDN)**, **TypeScript**, **Node.js**, **Python**, **Discord.js**, **React**, **Next.js**, **Express**, **Git**, **Docker**, **Rust**, **Go**, **Tailwind CSS**, و **Vue.js**.
  * نتائج مباشرة ودقيقة مع روابط التوثيق الرسمي.

---

### ⚡ 4. متابعة حالة الخدمات السحابية والبرمجية (Service Status)
* **`/status service:<service>`** — فحص الحالة التشغيلية والأعطال:
  * المنصات المدعومة: **GitHub**, **NPM**, **Discord**, **Cloudflare**, و **Vercel**.
  * مؤشرات الحالة اللحظية (🟢 يعمل بشكل طبيعي، 🟡 أداء منخفض، 🔴 عطل رئيسي، 🔵 صيانة).
  * تفاصيل الأعطال النشطة، تقييم التأثير، ورابط صفحة الحالة الرسمية.
* **`/status-all`** — لوحة القيادة المركزية لحالة جميع الخدمات في رسالة واحدة.

---

### 💡 5. أدوات وتجربة المطورين (Utilities)
* **`/help [command]`** — دليل الأوامر التفاعلي مع قائمة تصنيفات منسدلة.
* **`/ping`** — قياس سرعة استجابة البوت (WebSocket Heartbeat) وبنج ديسكورد API.
* **`/about`** — معلومات البوت، استهلاك الذاكرة، معدل نجاح الكاش، وإصدارات النظام.

---

## 🛡️ الأمان والمعمارية البرمجية

* **فصل طبقة الخدمات (Decoupled Services)**: جميع اتصالات الـ API الخارجية مفصولة تماماً داخل كلاسات خدمية مستقلة.
* **تشفير التوكنات (AES-256-GCM)**: حماية قصوى لبيانات وتوكنات GitHub OAuth وعدم تخزين أي بيانات حساسة بنص صريح.
* **التخزين المؤقت (In-Memory LRU Cache)**: تقليل استهلاك الـ Rate Limits وزيادة سرعة الاستجابة إلى أجزاء من الثانية.
* **الحماية من السبام (Cooldown Manager)**: نظام تهدئة مخصص لكل مستخدم ولكل أمر لمنع الإفراط في الاستخدام.

## 🚀 التثبيت والتشغيل السريع

### 1. المتطلبات الأساسية
* **Node.js**: إصدار 18.0.0 أو أحدث
* **npm**: إصدار 9.0.0 أو أحدث

---

### 2. تحميل المشروع وتثبيت المكتبات

```bash
git clone <repository-url>
cd serene-turing
npm install
```

---

### 3. إعداد ملف البيئة (`.env`)

انسخ ملف `.env.example` إلى `.env`:

```bash
cp .env.example .env
```

ضع بيانات البوت الخاصة بك في `.env`:

```env
# [مطلوب] توكن البوت من Discord Developer Portal
DISCORD_TOKEN=your_bot_token

# [مطلوب] معرف التطبيق Client ID
CLIENT_ID=your_client_id

# [مطلوب لـ GitHub OAuth] بيانات تطبيق جيت هب
GITHUB_CLIENT_ID=your_github_client_id
GITHUB_CLIENT_SECRET=your_github_client_secret

# [اختياري] توكن جيت هب لرفع حد الطلبات إلى 5000 طلب/ساعة
GITHUB_TOKEN=
```

---

### 4. تسجيل أوامر Slash في ديسكورد

لتسجيل الأوامر في جميع السيرفرات:

```bash
npm run deploy:commands
```

---

### 5. تشغيل البوت

**وضع التطوير (مع التحديث التلقائي):**
```bash
npm run dev
```

**وضع الإنتاج:**
```bash
npm run build
npm start
```

---

### 6. تشغيل الاختبارات

```bash
npm test
```
